## ☕ Página de Receita: Café com Chantilly

Um projeto de página web estática, focada em design e acessibilidade, dedicada a apresentar a receita completa do delicioso bolinho **Café com Chantilly**.

Este projeto foi desenvolvido como parte de um desafio educacional da **Rocketseat**.

## ✨ Recursos

* **Conteúdo Completo da Receita:** Detalhes de tempo de preparo, rendimento, dificuldade, ingredientes e modo de preparo.
* **Design Estilizado:** Utiliza uma paleta de cores quentes e tipografia "Alice" para uma estética aconchegante.
* **Estrutura Semântica:** Uso correto de tags HTML (`<main>`, `<section>`, `<footer>`, etc.) para melhor organização e acessibilidade.
* **Responsividade Básica:** Estrutura otimizada para ser visualizada em telas de até 800px de largura.

## 🛠️ Tecnologias Utilizadas

Este site é 100% estático e foi construído usando as tecnologias fundamentais da web:

* **HTML5:** Para estruturação do conteúdo e organização das seções (`<section id="ingredients">`, `<section id="preparation">`).
* **CSS3:** Para a estilização e design, incluindo o uso da fonte "Alice" e "Inter" do Google Fonts.

## 🚀 Como Acessar e Rodar o Projeto

### Pré-requisitos

Você só precisa de um navegador web moderno (como Chrome, Firefox ou Edge).
